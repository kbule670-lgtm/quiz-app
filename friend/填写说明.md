# 题库怎么给我（3 分钟看懂）

下面几个方式挑一个顺手的，弄好发回给我就行。

## 方式零：直接发 PDF / Word（最省事，有现成文件就用这个）

老师发的题库 PDF、Word 本身就能直接导进 App，不用你转换，前提是排版长这样：

- 每道题有题号（1. 2. 3. 这样）
- 四个选项带 A B C D 标记
- 有答案（写「答案：B」，或在题干后面标（B），都行），解析有最好、没有也行

注意两种情况导不了：
- **扫描/拍照的 PDF**（打开全是图片、文字选不中的那种）导不了，得先转成文字版
- **老版 .doc 文件**（不是 .docx）先在 WPS/Word 里另存为 .docx

排版拿不准的话，照 `question-bank-template.txt` 那个文字模板的样子对一遍就行。

## 方式一：用表格填（推荐）

打开 `question-bank-template.csv`（Excel / WPS / Numbers 都能打开），照着填：

| 列 | 填什么 |
|---|---|
| 题干 | 题目本身 |
| 选项A～D | 四个选项，一道题必须 4 个 |
| 答案 | 只写 A、B、C、D 其中一个字母 |
| 解析 | 可空，不写也行 |

注意：
- 第一行是表头，别删；示例那两行删掉换成你的题
- 选项里如果有逗号，用英文双引号把整个选项包起来，比如 `"红，黄，蓝"`
- 题量不限，几十道几百道都行；先发 5 道样题也行，我先验证能导进去

## 方式二：用 JSON 填（如果你会）

照 `question-bank-template.json` 的格式，每道题就是一段：

```json
{
  "stem": "题干",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": "B",
  "explanation": "解析，可空"
}
```

答案写 A/B/C/D 的字母。示例那两段删掉换成你的题。
