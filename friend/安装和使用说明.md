# 刷题 App · 安装和使用（看这份就够了）

## 一、装到手机上

你会收到一个 `.ipa` 文件，这是安装包。iPhone 不能直接点开装，要先用**全能签**签一下：

1. 把收到的 ipa 保存到手机的「文件」App 里（在聊天里长按文件 → 存储到文件）
2. 打开全能签 → 找到这个 ipa → 点「签名」→ 选你自己的证书 → 签名后安装
3. 如果打开 App 时提示「未受信任的开发者」：去 设置 → 通用 → VPN与设备管理 → 点你的证书 → 信任，再回来打开

> 注意：一定要用**你自己手机上可用的证书**签。用别人签好的包大概率装不上，这是苹果的规矩，不是包坏了。

## 二、导入题库

题库你自己导，不用麻烦任何人，全程在你自己手机里，不联网、不上传：

1. 先把题库文件存到「文件」App 里（微信/QQ 收到的文件，长按 → 存储到文件）
2. 打开刷题 App → 底部「题库」页 → 「从文件导入题库」→ 选中文件 → 导入成功会告诉你一共多少道

能导的格式：

- **PDF / Word（.docx）**：老师发的原文件直接导。要求里面是有题号、A/B/C/D 选项、带答案的
- **表格 CSV / JSON**：照模板填的那种
- **txt**：照文字模板排版的

导不了的两种（App 会直接告诉你原因）：

- 扫描/拍照版 PDF（全是图片的）——先转成文字版再导
- 老版 .doc——在 WPS 里另存为 .docx 再导

## 三、刷题

- 「刷题」页：选顺序还是随机 → 开始。一题一屏，点选项立刻判对错，错了会标出正确答案和解析
- 答错的题**自动进错题本**，不用手动收
- 「错题本」页：一键重做错题，做对一次就自动移出
- 进度自动存在手机里，关掉 App、重启手机都不丢，下次打开接着刷

## 四、提醒一句

题库和刷题记录只存在你这台手机上，**删了 App 就全没了**。题库攒多了，偶尔在「题库」页点一次「生成题库导出文件」，把导出的文件存好，算个备份。
